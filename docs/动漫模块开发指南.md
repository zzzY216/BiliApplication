# 动漫模块开发指南（番剧 / 国创）

> 配套文档：《BiliApplication API 接口文档.md》（§11 番剧/影视 PGC）、《重构记录-第二轮.md》。
> 本文档整理动漫模块所需的全部材料：接口清单、数据模型（真实字段）、网络层/仓储设计、
> UI 结构与分阶段实施步骤。字段名取自 PiliPlus 的 `lib/models_new/pgc/` 模型定义（经过实际请求验证）。

---

## 1. 模块定位（架构决策，与既有共识一致）

| 问题 | 结论 |
| --- | --- |
| 动漫是独立 feature 吗？ | **现在不是**。按《重构记录》结论：动漫是 home 里 MusicTopBar 的一个 Tab 内容槽（与博客/有声书/广播剧/听书并列），**不新建 `feature:anime`** |
| 什么时候抽独立 feature？ | 当详情页 + 播放页落地、home 自身膨胀时，再抽 `feature:anime`（有独立子导航链：列表→详情→播放→评论） |
| 数据层怎么办？ | **数据层先行独立**：PGC 是完整内容域（索引/排行/时间线/详情/追番/评分），单独建 `BangumiRepository`（不塞进已 9 个方法的 `VideoRepository`） |
| 分层归属 | `core:model` 加 PGC 模型 → `core:network` 加 PgcApiService → `core:data` 加 BangumiRepository → `features:home` 加 anime 子包（UI） |

```
features:home
├── MusicTopBar(tabs=[博客,有声书,广播剧,听书,动漫])
└── when(selectedTab) {
        ...
        动漫 -> AnimeTabContent()      // home/anime/ 子包，本模块
    }
core:data  BangumiRepository           // 索引分页流 + 排行/时间线/详情/追番/互动
core:network  PgcApiService            // /pgc/... 与 /x/space/bangumi/... 接口
core:model  SeasonCard/SeasonDetail/Episode/Timeline 等
```

## 2. 接口清单（动漫模块完整数据源）

> 鉴权标记：🔓公开 ｜ 🔐需登录Cookie ｜ ✍️写操作需 csrf（=`bili_jct`，`BiliSessionManager` 已维护）｜ ⚠️WBI 需 wbi 签名。

### 2.1 列表类（Tab 内容：索引 / 排行 / 时间线）

| 功能 | 方法 | URL | 鉴权 | 关键参数 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 番剧索引-筛选条件 | GET | `/pgc/season/index/condition` | 🔓 | `type`、`season_type`(1 番剧/4 国创)、`index_type` | 年份/地区/类型筛选项 |
| 番剧索引-结果 | GET | `/pgc/season/index/result` | 🔓 | `page`、`pagesize`(20-21)、`season_type`、`type`、`year`、`area`、`is_finish`、`order`、`sort` | **分页**，`data.list[]`（`PgcIndexItem`） |
| 番剧排行 | GET | `/pgc/web/rank/list` | 🔓⚠️WBI | `day`(3/7/30)、`season_type` | `data.list[]`（`PgcRankItemModel`） |
| 番剧季度榜 | GET | `/pgc/season/rank/web/list` | 🔓⚠️WBI | `day`、`season_type` | 同上 |
| 新番时间线 | GET | `/pgc/web/timeline` | 🔓 | `types`(1 番剧/3 电影/4 国创)、`before`(向前天数)、`after`(向后天数) | `data.result[]`，按日分组（`TimelineResult`） |

> **season_type 取值**：1=番剧，2=电影，3=纪录片，4=国创，5=电视剧，6=综艺。动漫 = 番剧(1) + 国创(4)。

## 4. 网络层（`core:network` 新增 `PgcApiService`）

> 全部走 `api.bilibili.com`，复用现有 `@BiliApiNetwork` 限定的 Retrofit 实例，无需新 baseUrl。

```kotlin
package com.software.core.network

import com.software.core.model.BiliResponse
import com.software.core.model.pgc.PgcIndexItem
import com.software.core.model.pgc.PgcRankItem
import com.software.core.model.pgc.SeasonDetailResponse
import com.software.core.model.pgc.TimelineResult
import retrofit2.http.GET
import retrofit2.http.POST
import retrofit2.http.Query
import retrofit2.http.FormUrlEncoded
import retrofit2.http.Field

interface PgcApiService {

    /** 番剧索引结果（分页） */
    @GET("pgc/season/index/result")
    suspend fun getIndexResult(
        @Query("page") page: Int,
        @Query("pagesize") pageSize: Int = 21,
        @Query("season_type") seasonType: Int = 1,   // 1 番剧 / 4 国创
        @Query("order") order: Int = 3,              // 3 更新时间
        @Query("sort") sort: Int = 0,
        @Query("year") year: Int? = null,
        @Query("area") area: Int? = null,
        @Query("is_finish") isFinish: Int? = null,
    ): BiliResponse<PgcIndexData>

    /** 番剧排行 */
    @GET("pgc/web/rank/list")
    suspend fun getRank(
        @Query("day") day: Int = 3,
        @Query("season_type") seasonType: Int = 1,
    ): BiliResponse<PgcRankData>

    /** 新番时间线 */
    @GET("pgc/web/timeline")
    suspend fun getTimeline(
        @Query("types") types: Int = 1,     // 1 番剧 / 4 国创
        @Query("before") before: Int = 7,
        @Query("after") after: Int = 7,
    ): BiliResponse<PgcTimelineData>

    /** 剧集明细 */
    @GET("pgc/view/web/season")
    suspend fun getSeasonDetail(@Query("season_id") seasonId: Long): BiliResponse<SeasonDetailResponse>

    /** 追番状态 */
    @GET("pgc/view/web/season/user/status")
    suspend fun getSeasonUserStatus(@Query("season_id") seasonId: Long): BiliResponse<Map<String, Any?>>

    /** PGC 播放地址 */
    @GET("pgc/player/web/v2/playurl")
    suspend fun getPlayUrl(
        @Query("ep_id") epId: Long,
        @Query("cid") cid: Long,
        @Query("qn") qn: Int = 64,
        @Query("fnval") fnval: Int = 4048,
    ): BiliResponse<PgcPlayUrlResponse>

    /** 追番 */
    @FormUrlEncoded
    @POST("pgc/web/follow/add")
    suspend fun followSeason(
        @Field("season_id") seasonId: Long,
        @Field("csrf") csrf: String,
    ): BiliResponse<Any?>

    /** 取消追番 */
    @FormUrlEncoded
    @POST("pgc/web/follow/del")
    suspend fun unfollowSeason(
        @Field("season_id") seasonId: Long,
        @Field("csrf") csrf: String,
    ): BiliResponse<Any?>

    /** 分集互动状态（点赞/投币/收藏） */
    @GET("pgc/season/episode/community")
    suspend fun getEpisodeCommunity(@Query("ep_id") epId: Long): BiliResponse<PgcCommunityData>
}

// --- 数据包装（核心字段）---
@kotlinx.serialization.Serializable
data class PgcIndexData(val list: List<PgcIndexItem>? = null)

@kotlinx.serialization.Serializable
data class PgcRankData(val list: List<PgcRankItem>? = null)

@kotlinx.serialization.Serializable
data class PgcTimelineData(val result: List<TimelineResult>? = null)

@kotlinx.serialization.Serializable
data class PgcPlayUrlResponse(
    val result: PgcPlayUrlResult? = null,
)

@kotlinx.serialization.Serializable
data class PgcPlayUrlResult(
    val videoInfo: PlayUrlData? = null,   // 复用现有 PlayUrlData（core.model）
    val lastPlayTime: Long? = null,       // 续播进度
)

@kotlinx.serialization.Serializable
data class PgcCommunityData(
    val like: Int? = null,
    val coin: Int? = null,
    val favorite: Int? = null,
)
```

> 接入方式：在 `NetworkModule` 加一个 `@Provides`（`@BiliApiNetwork` 的 Retrofit 实例上 `create(PgcApiService::class.java)`），
> 与现有 `BiliApiService` 同模式。PgcApiService 的 `csrf` 参数由数据层从 `BiliSessionManager.cookieFlow` 读取后传入。

## 5. 数据层（`core:data` 新增 `BangumiRepository`）

```kotlin
package com.software.core.data.repository

import androidx.paging.PagingData
import com.software.core.model.pgc.PgcEpisode
import com.software.core.model.pgc.PgcIndexItem
import com.software.core.model.pgc.PgcRankItem
import com.software.core.model.pgc.SeasonDetail
import com.software.core.model.pgc.TimelineResult
import kotlinx.coroutines.flow.Flow

interface BangumiRepository {
    /** 番剧索引分页流（动漫 Tab 主内容） */
    fun getIndexPagingFlow(seasonType: Int = 1): Flow<PagingData<PgcIndexItem>>

    /** 番剧排行（一次性） */
    suspend fun getRank(seasonType: Int = 1, day: Int = 3): Result<List<PgcRankItem>>

    /** 新番时间线（一次性） */
    suspend fun getTimeline(types: Int = 1): Result<List<TimelineResult>>

    /** 剧集明细 */
    suspend fun getSeasonDetail(seasonId: Long): Result<SeasonDetail>

    /** PGC 播放地址 */
    suspend fun getPlayUrl(episode: PgcEpisode, qn: Int): Result<PlayUrlData>

    /** 追番 / 取消追番 */
    suspend fun setFollow(seasonId: Long, follow: Boolean): Result<Unit>

    /** 分集互动状态（赞/币/藏） */
    suspend fun getEpisodeCommunity(epId: Long): Result<PgcCommunityData>
}
```

- 实现 `BangumiRepositoryImpl`：`@Inject constructor(@BiliApiNetwork apiService: PgcApiService, sessionManager: BiliSessionManager)`，
  仿照 `VideoRepositoryImpl`（索引用 `PagingSource` + `flow`，`biliApiCall` 包装错误）；
- 绑定：`DataModule` 加 `@Binds abstract fun bindBangumiRepository(impl: BangumiRepositoryImpl): BangumiRepository`；
- csrf 获取：`sessionManager.cookieFlow().first()` 解析 `bili_jct`（参考 `likeVideo` 现有写法）。

## 6. UI 结构（`features:home` 新增 `anime` 子包）

```
features/home/src/main/java/com/software/home/anime/
├── AnimeTabContent.kt     // 动漫 Tab 内容槽：三个子页签（推荐/排行/时间线）
├── AnimeViewModel.kt      // 索引分页流 cachedIn + 排行/时间线一次性加载
├── AnimeUiState.kt
└── SeasonCard.kt          // 通用番剧卡片（封面+标题+副标题+角标）
```

- **MusicTopBar**：`defaultMusicTabs` 追加 `"动漫"`；`BiliHomeScreen` 的 `when(selectedTab)` 加分支 `动漫 -> AnimeTabContent()`；
- **AnimeTabContent**：内部用 `ScrollableTabRow` 或 `SegmentedButton` 切换 推荐/排行/时间线：
  - 推荐：`LazyColumn + LazyPagingItems<PgcIndexItem>`（与现有推荐流同模式）；
  - 排行：一次性 `StateFlow<List<PgcRankItem>>`，`PagingConfig` 不需要；
  - 时间线：按 `TimelineResult` 分组展示当天更新；
- **SeasonCard**：`AsyncImage(cover) + Text(title) + badge/rating 角标`，点击 → 详情页（M3 阶段加路由）；
- 卡片组件放 `anime/` 包内（当前仅动漫用）；若未来 UGC 视频详情也复用，再提到 designsystem。

## 7. 实施步骤（建议顺序）

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| **M1 数据层** | ① core:model 加 `pgc` 包模型（§3）→ ② core:network 加 `PgcApiService` + NetworkModule 绑定（§4）→ ③ core:data 加 `BangumiRepository` + PagingSource + DataModule 绑定（§5） | `:core:data:compileDebugKotlin` 通过；可写单测验证 JSON 解析 |
| **M2 动漫 Tab** | ④ MusicTopBar 加"动漫" → ⑤ `AnimeTabContent`（推荐索引流 + 排行 + 时间线）→ ⑥ `SeasonCard` | `:app:assembleDebug` 通过，模拟器可见动漫列表 |
| **M3 详情页** | ⑦ 详情路由 `AnimeDetailRoute(seasonId)`（core:model.navigation 加路由）→ ⑧ 详情 UI（封面/简介/分集列表/追番按钮/评分）→ ⑨ `setFollow` 接追番 | 列表点进详情、可追番 |
| **M4 播放+互动** | ⑩ PGC playurl + media3 播放器（复用预留的 exoplayer 依赖）→ ⑪ 三连/收藏剧集 → ⑫ 短评列表+发表（`pgc/review/*`） | 可播放、可评分评论 |

> 推荐先把 M1 一次做完（数据层可独立验证），M2–M4 按 UI 优先级穿插。

## 9. 注意事项

1. **接口域名**：PGC 接口全在 `api.bilibili.com`，走现有 `@BiliApiNetwork` 通道，**无 appSign 门槛**；
2. **WBI**：排行接口（`/pgc/web/rank/list`）当前需要 wbi 签名，M2 若遇到 `-403`，给 `BangumiRepository` 补 `WbiSign`（PiliPlus 的 `wbi_sign.dart` 有现成算法，密钥来自 `/x/web-interface/nav` 的 `wbi_img`）；
3. **详情 data 结构**：`/pgc/view/web/season` 返回 `data.result`，包装类（§3.3）别漏；
4. **时长单位**：PGC `duration` 是毫秒（UGC 是秒），播放器换算注意；
5. **播放免登录**：PGC playurl 未登录可看（部分番剧需大会员），`try_look` 语义与 UGC 不同，先按 qn=64 起播。
